# Security Policy

## Supported Versions

We provide security patches and dependency updates for the latest released version:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The ChromaMetrics team takes security issues seriously. If you discover a security vulnerability in ChromaMetrics or one of its components, please do not file a public issue.

Instead, please send an email to:
**l.tesoro.554639@umindanao.edu.ph**

Include the following details where possible:
- Description of the potential vulnerability
- Steps or proof-of-concept to reproduce the behavior
- Any potential remediations or configurations that mitigate the issue

We appreciate your effort in practicing responsible disclosure and will acknowledge receipt of your vulnerability report within 48 hours.
